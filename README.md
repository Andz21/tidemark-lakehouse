# Tidemark Lakehouse

Tidemark Lakehouse is a lightweight Python project scaffold for building lakehouse-style data and analytics workflows.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e .
pytest
```

## Project structure

- `src/tidemark/` - application package
- `tests/` - automated tests
- `docs/` - design notes and ADRs
- `resources/` - supporting assets

This repository is intentionally small and ready to extend as the project grows.
